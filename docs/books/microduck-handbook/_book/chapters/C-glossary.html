附录 C — 附录 C：术语表

术语 含义
Actor PPO 中负责根据观测选择动作的策略网络；部署时通常只需 actor。
Applied command 经过服务选择和安全处理后，当前实际生效的控制目标。
BAM 用于模拟实际执行器物理的模型/工具链；此项目针对 XL330 加入电压和摩擦影响。
Deadman 定期续期的控制意图租约；客户端停止刷新后系统让机器人停止。
Domain randomization 训练期间在合理范围随机化物理和传感器参数，提升变化条件下的鲁棒性。
EPUB 面向电子书阅读器的开放电子书格式，支持目录、章节导航和可重排文字。
IPC 不同进程之间的通信；此运行时主要使用 Unix socket 和 JSON-RPC。
MJCF MuJoCo 使用的模型描述格式，定义身体几何、关节、质量、接触和传感器。
MDP 马尔可夫决策过程；强化学习环境用它定义状态、动作、奖励、转移和结束。
mocap MuJoCo 的运动捕获/运动学刚体；场景控制代码直接更新它的位置与姿态。
Observation 策略接收的数值状态向量；本项目可部署 actor 合同是 61 维。
ONNX 跨运行时的神经网络交换格式，用于把训练结果交给机器人推理引擎。
PPO 近端策略优化算法；本训练仓库用于从模拟经验更新策略。
RemoteIo robotd 中通过网络连接远程 MuJoCo 身体的仿真 I/O 实现。
Sim2real 将仿真训练或验证得到的策略迁移到真实机器人硬件。
ToF Time of Flight 飞行时间测距传感器；本项目头部深度模组提供稀疏 8×8 距离。
UYVY 交错的 YUV 4:2:2 像素格式；模拟相机帧通道以此格式传图。
VIO / odometry 视觉惯性定位或局部里程计；当前 odometry 主要结合脚部锚点与 IMU。
WebRTC 实时音视频与数据传输技术；机器人控制台用它传视频和远程控制通道。
YOLO 一类实时目标检测模型家族；本实验使用 Ultralytics 预训练权重识别 COCO 类别。
观测归一化 对策略输入进行尺度变换；导出时必须与训练和运行时的合同保持一致。
策略槽位 robotd 配置中的命名模型位置，例如 walking 或 recover 等不同用途。
控制意图 上层请求的速度或行为目标，不等于单个关节的直接伺服命令。
